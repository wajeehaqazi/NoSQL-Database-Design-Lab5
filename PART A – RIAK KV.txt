PART A – RIAK KV

Q1. Install Riak KV and perform basic key-value operations on Students bucket.
Code:
# Create bucket
curl -X PUT http://localhost:8098/buckets/students/props \
-H "Content-Type: application/json" \
-d '{"props":{"allow_mult":false}}'

# Insert student
curl -X PUT http://localhost:8098/buckets/students/keys/101 \
-H "Content-Type: application/json" \
-d '{"name":"Aman","course":"BCA","city":"Agra"}'

# Retrieve student
curl http://localhost:8098/buckets/students/keys/101

# Update student
curl -X PUT http://localhost:8098/buckets/students/keys/101 \
-H "Content-Type: application/json" \
-d '{"name":"Aman","course":"MCA","city":"Agra"}'

# Delete student
curl -X DELETE http://localhost:8098/buckets/students/keys/101

Output:
Bucket created successfully.

Student inserted:
{
  "name": "Aman",
  "course": "BCA",
  "city": "Agra"
}

After Update:
{
  "name": "Aman",
  "course": "MCA",
  "city": "Agra"
}

Student deleted successfully.

Q5. Demonstrate key-value data structure using Riak.
Code:
# Store string
curl -X PUT http://localhost:8098/buckets/data/keys/name \
-H "Content-Type: text/plain" \
-d 'Aman'

# Store JSON
curl -X PUT http://localhost:8098/buckets/data/keys/student \
-H "Content-Type: application/json" \
-d '{"name":"Riya","course":"BCA"}'

# Store list
curl -X PUT http://localhost:8098/buckets/data/keys/subjects \
-H "Content-Type: application/json" \
-d '["Java","Python","NoSQL"]'

# Retrieve values
curl http://localhost:8098/buckets/data/keys/name

curl http://localhost:8098/buckets/data/keys/student

curl http://localhost:8098/buckets/data/keys/subjects

Output:
String:
Aman

JSON:
{"name":"Riya","course":"BCA"}

List:
["Java","Python","NoSQL"]

Explanation:
- Bucket: Stores related keys.
- Key: Identifies a particular record.
- Value: Stores actual data.
Q6. Demonstrate consistency using read and write quorum.
Code:
# Create bucket with quorum settings
curl -X PUT http://localhost:8098/buckets/consistency/props \
-H "Content-Type: application/json" \
-d '{
"props":{
"n_val":3,
"allow_mult":false
}
}'

# Write operation
curl -X PUT \
"http://localhost:8098/buckets/consistency/keys/101?w=quorum&dw=quorum" \
-H "Content-Type: application/json" \
-d '{"name":"Aman","course":"BCA"}'

# Read operation
curl \
"http://localhost:8098/buckets/consistency/keys/101?r=quorum"

Output:
Bucket created successfully.

Write Operation:
Data stored successfully.

Read Operation:
{
  "name": "Aman",
  "course": "BCA"
}

Explanation:
- R = Read quorum.
- W = Write quorum.
- Quorum means the required number of replicas.
- Riak uses replicas to improve data availability and consistency.
Q7. Demonstrate scaling using Riak KV.
Code:
# Create multiple buckets
curl -X PUT http://localhost:8098/buckets/users/props \
-H "Content-Type: application/json" \
-d '{"props":{"allow_mult":false}}'

curl -X PUT http://localhost:8098/buckets/products/props \
-H "Content-Type: application/json" \
-d '{"props":{"allow_mult":false}}'

# Insert user records
curl -X PUT http://localhost:8098/buckets/users/keys/1 \
-d '{"name":"Aman"}'

curl -X PUT http://localhost:8098/buckets/users/keys/2 \
-d '{"name":"Riya"}'

# Insert product records
curl -X PUT http://localhost:8098/buckets/products/keys/1 \
-d '{"product":"Laptop"}'

curl -X PUT http://localhost:8098/buckets/products/keys/2 \
-d '{"product":"Mobile"}'

# Retrieve records
curl http://localhost:8098/buckets/users/keys/1

curl http://localhost:8098/buckets/products/keys/1

Output:
Users Bucket:
1 - Aman
2 - Riya

Products Bucket:
1 - Laptop
2 - Mobile

Records inserted successfully.

Explanation:
- Riak distributes data across multiple nodes.
- New nodes can be added to increase capacity.
- This is called horizontal scaling.

Q10. Implement Set Operations using Riak.
Code:
# Create set
curl -X PUT http://localhost:8098/types/sets/buckets/interests/keys/U1 \
-H "Content-Type: application/json" \
-d '{
"add":["Music","Sports","Reading"]
}'

# Retrieve set
curl http://localhost:8098/types/sets/buckets/interests/keys/U1

# Add new element
curl -X POST \
http://localhost:8098/types/sets/buckets/interests/keys/U1 \
-H "Content-Type: application/json" \
-d '{"add":["Coding"]}'

# Remove element
curl -X POST \
http://localhost:8098/types/sets/buckets/interests/keys/U1 \
-H "Content-Type: application/json" \
-d '{"remove":["Sports"]}'

# Retrieve updated set
curl http://localhost:8098/types/sets/buckets/interests/keys/U1

Output:
Initial Set:
Music, Sports, Reading

After Adding:
Music, Sports, Reading, Coding

After Removing:
Music, Reading, Coding
